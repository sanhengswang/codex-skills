# 王涛的协作约定

## 输出方式

- 一律中文，结论先行，再展开细节。
- 列表、表格优先；命令和路径用反引号标出。
- 不长篇解释原理，用户追问再展开。

## 动手之前

- 先用一句话说明准备做什么。
- 删除文件或文件夹、批量重命名 / 移动、覆盖已有文件：先列清单，等用户说“可以”。
- 不确定意图时先问一句，不猜着做。

## 动手之后

- 用一段话总结：改了哪些文件、结果如何。
- 没做成直说卡点和报错，不含糊。

## 安全边界

- 不读写 `C:\Windows`、`C:\Program Files*`、注册表、系统服务。
- 不修改 `~/.codex/config.toml`。
- 不执行 `codex app`，不擅自联网安装新软件。
- 不往工作目录之外写文件；需要时先问。

## 常用路径

| 用途 | 路径 |
|---|---|
| 工作区 | `D:\workbuddy\Claw` |
| 桌面 | `C:\Users\天天\Desktop` |
| 毕设·岩头村老戏台 | `C:\Users\天天\Desktop\台巷水` |
| 棒球队官网 | `D:\workbuddy\Claw\baseball` |

## 任务节奏

- 一次只推进一件事，不擅自把后面十步都做完。
- 超过 1 分钟的任务，先报预估耗时和会动的文件。
- 看文件先给“数量 / 大小 / 类型”概览，再给明细。

## 不熟悉的开发需求

先调研 GitHub 上维护活跃、许可证清晰的开源实现，输出候选清单、优缺点、依赖、许可证与风险，再给设计方案，最后写代码。不复制来源不明或许可证不兼容的源码。
